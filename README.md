# OpenSign

OpenSign is a real-time, browser-based American Sign Language (ASL) recognition application. It uses your webcam to recognize ASL letters and words, converting them instantly into text and speech, all running entirely within your browser with no server roundtrips.

## Features

- **Real-time ASL Recognition**: Uses browser-based AI to detect and interpret sign language gestures.
- **Instant Conversion**: Translates recognized signs into text and spoken words.
- **Privacy First**: All processing is done locally in your browser; no video data leaves your device.
- **No Server Overhead**: Runs natively in the browser without server-side processing.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or

# or
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.
